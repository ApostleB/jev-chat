**Goal:** 챗봇 동작을 확인하는 내부 도구를 만든다 — 테스트 채팅 + 실시간 판단 패널, 대화 로그 + trace 서랍, 검수 대기, 지식 데이터, 설정.

## Global Constraints

- 공통 규칙(한국어, 커밋 trailer, push 금지, `.env*` 읽기 금지)을 따른다.
- **토큰·키를 번들에 넣지 않는다.** `VITE_` 변수는 `VITE_API_URL`(서버 주소, 비밀 아님)만 쓴다. 접속 토큰은 사용자가 설정 화면에서 입력하고 **`sessionStorage`에만** 저장하며 로그아웃 시 즉시 삭제한다.
- 서버가 준 텍스트(답변·원문·trace)는 **일반 텍스트로만 렌더링**한다. `dangerouslySetInnerHTML` 금지, Markdown 해석 금지. 줄바꿈은 CSS `white-space: pre-wrap`.
- 소켓 이벤트는 ack보다 먼저 올 수 있다 → 턴 상태는 `clientMsgId` 기준 upsert. 재연결 시 `session:start`로 최신 50턴을 받아 upsert한다.
- "다시 보내기" [U2]: ack를 받지 못한 **미확정** 실패는 **같은 clientMsgId·같은 text**로 복구 재전송(서버 멱등 → `duplicate`/`accepted`), 서버가 실패를 확정한 경우(`ok:false`, failed 턴, route=error)만 **새 clientMsgId** + `retryOfTurnSeq`.
- [U1] 소켓 ack·이벤트를 포함한 모든 서버 데이터는 `@jev-chat/protocol` zod 스키마로 검증한 뒤에만 상태에 반영한다(타입 단언 금지).
- [U3] 오래된 연결·세션의 늦은 응답은 세대·sessionId 검사로 버린다. [U4] 소켓 연결과 대화 세션 준비(`SessionState`)를 구분하고 세션이 ready일 때만 전송한다.
- [U6] 로그아웃·토큰 교체 시 Query 캐시·진행 요청·채팅 연결을 모두 정리한다(인증 세대 `authEpoch`). React Query는 v5 객체 시그니처만 쓴다 [U5].
- 서버 미들웨어가 연결을 거부하면(`connect_error`) socket.io-client는 자동 재연결하지 않는다 → 오류 코드를 보여주고 사용자가 다시 연결한다.
- 최근 메이저가 바뀐 라우터·테이블·모킹 라이브러리는 쓰지 않는다(화면 전환은 상태, 표는 shadcn Table 마크업, 테스트 모킹은 직접 만든 가짜 객체).

```ts
const KEY = "jev-chat.token";

/** 접속 토큰은 탭 수명(sessionStorage)으로만 보관한다. 번들·localStorage에 두지 않는다. */
export function getToken(): string | null {
  return sessionStorage.getItem(KEY);
}
export function setToken(token: string): void {
  const t = token.trim();
  if (t) sessionStorage.setItem(KEY, t);
}
export function clearToken(): void {
  sessionStorage.removeItem(KEY);
}

export const API_URL: string = import.meta.env.VITE_API_URL ?? "http://localhost:3000";
```

**Files:**

- Test: `jev-front/src/lib/api-client.spec.ts`, `jev-front/src/lib/turns.spec.ts`

**Interfaces:**
- Produces:
  - `class ApiRequestError extends Error { status: number; code: ErrorCode; retryAfterMs?: number }`
  - `class ApiClient` — `constructor(baseUrl: string, getToken: () => string | null, fetchImpl?: typeof fetch)`, `get<T>(path: string, schema: z.ZodType<T>): Promise<T>`, `post<T>(path: string, body: unknown, schema: z.ZodType<T>): Promise<T>`
  - `interface SendError { code: ErrorCode; message: string; retryable: boolean; uncertain: boolean }` — `uncertain=true`는 ack를 받지 못해 서버 수락 여부를 모르는 상태 [U2]
  - `type UiTurn = Turn & { localId: string; stage?: "queued" | "judging" | "answering"; sendError?: SendError }`
  - `interface TurnsState { sessionId: string | null; byClientId: Record<string, UiTurn>; traces: Record<string, Record<string, unknown>> }`
  - `type TurnsAction` — **모든 액션이 sessionId를 싣는다**[U3]: `{ type: "hydrate"; sessionId; turns: Turn[] } | { type: "localSend"; sessionId; clientMsgId; text } | { type: "ack"; sessionId; clientMsgId; turnId; turnSeq } | { type: "ackFailed"; sessionId; clientMsgId; error: SendError } | { type: "status"; e: ChatStatusEvent } | { type: "done"; e: ChatDoneEvent } | { type: "error"; e: ChatErrorEvent } | { type: "trace"; sessionId; e: ChatTraceEvent } | { type: "reset" }`
  - `turnsReducer(state, action): TurnsState`, `initialTurns: TurnsState`, `orderedTurns(state): UiTurn[]` (turnSeq 오름차순, 아직 seq 없는 로컬 전송은 맨 뒤 입력 순)

리듀서 규칙:
- `hydrate`만 세션을 바꿀 수 있다(다른 sessionId면 새 상태로 시작). 그 외 액션은 `state.sessionId`와 sessionId가 다르면 무시한다 [U3].
- 서버의 terminal 결과(`done`, `error`, terminal 상태의 `hydrate`)는 로컬 `sendError`·`stage`를 지운다. terminal 이후의 `ackFailed`는 무시한다 [U2].
- `status` 수신은 서버가 수락했다는 증거이므로 `sendError`(미확정 포함)를 지운다 [U2].
- terminal 턴에 늦게 온 비-terminal `hydrate`는 상태·답변을 유지하되, 비어 있는 메타데이터(`userText`, `turnId`, `turnSeq`)는 보충한다 [U8].
- 같은 턴에 `done`과 `error`가 모두 오면 먼저 온 terminal을 유지한다(서버는 하나만 보내지만 방어) [U8].

```ts
/** 실제 Response를 돌려주는 가짜 fetch. 호출 기록을 남긴다. */
export function fakeFetch(routes: Record<string, { status: number; body: unknown }>) {
  const calls: { url: string; init?: RequestInit }[] = [];
  const fn = async (url: string, init?: RequestInit) => {
    calls.push({ url, init });
    const u = new URL(url);
    const key = `${init?.method ?? "GET"} ${u.pathname}${u.search}`;
    const r = routes[key] ?? { status: 404, body: { error: { code: "NOT_FOUND", message: "없음" } } };
    return new Response(JSON.stringify(r.body), { status: r.status, headers: { "content-type": "application/json" } });
  };
  return { fn: fn as unknown as typeof fetch, calls };
}

type Handler = (...args: unknown[]) => void;

/** 테스트가 끝날 때까지 결과를 쥐고 있는 Promise */
export function deferred<T>() {
  let resolve!: (v: T) => void;
  let reject!: (e: unknown) => void;
  const promise = new Promise<T>((res, rej) => {
    resolve = res;
    reject = rej;
  });
  return { promise, resolve, reject };
}

/**
 * socket.io-client Socket의 필요한 부분만 흉내 낸다. [U7]
 * - connect()는 연결 시도만 표시한다(이미 연결 중이면 아무것도 안 함). 서버 handshake 완료(`connect` 이벤트)는
 *   테스트가 `serverEmit("connect")`로 명시적으로 일으킨다.
 * - ackResponder는 값·Promise를 돌려주거나 throw해서 ack 지연·유실을 흉내 낸다.
 */
export class FakeSocket {
  connected = false;
  connectCalls = 0;
  readonly emitted: { event: string; payload: unknown }[] = [];
  private handlers = new Map<string, Set<Handler>>();
  ackResponder: (event: string, payload: unknown) => unknown = () => ({ ok: true, data: {} });

  on(event: string, h: Handler) {
    if (!this.handlers.has(event)) this.handlers.set(event, new Set());
    this.handlers.get(event)!.add(h);
    return this;
  }
  off(event: string, h?: Handler) {
    if (h) this.handlers.get(event)?.delete(h);
    else this.handlers.delete(event);
    return this;
  }
  listenerCount(): number {
    let n = 0;
    for (const s of this.handlers.values()) n += s.size;
    return n;
  }
  /** 서버 → 클라이언트 이벤트 흉내 */
  serverEmit(event: string, ...args: unknown[]) {
    if (event === "connect") this.connected = true;
    if (event === "disconnect") this.connected = false;
    for (const h of [...(this.handlers.get(event) ?? [])]) h(...args);
  }
  connect() {
    this.connectCalls++;
    return this;
  }
  disconnect() {
    this.connected = false;
    return this;
  }
  timeout(_ms: number) {
    return {
      emitWithAck: async (event: string, payload: unknown) => {
        this.emitted.push({ event, payload });
        return await this.ackResponder(event, payload);
      },
    };
  }
}
```

```ts
import { ApiErrorSchema, type ErrorCode } from "@jev-chat/protocol";
import type { z } from "zod";

export class ApiRequestError extends Error {
  constructor(readonly status: number, readonly code: ErrorCode, message: string, readonly retryAfterMs?: number) {
    super(message);
    this.name = "ApiRequestError";
  }
}

export class ApiClient {
  constructor(
    private readonly baseUrl: string,
    private readonly getToken: () => string | null,
    private readonly fetchImpl: typeof fetch = (...a) => fetch(...a),
  ) {}

  get<T>(path: string, schema: z.ZodType<T>): Promise<T> {
    return this.request("GET", path, undefined, schema);
  }

  post<T>(path: string, body: unknown, schema: z.ZodType<T>): Promise<T> {
    return this.request("POST", path, body, schema);
  }

  private async request<T>(method: string, path: string, body: unknown, schema: z.ZodType<T>): Promise<T> {
    const token = this.getToken();
    if (!token) throw new ApiRequestError(401, "UNAUTHORIZED", "접속 토큰을 먼저 입력하세요.");
    const res = await this.fetchImpl(`${this.baseUrl}${path}`, {
      method,
      headers: { authorization: `Bearer ${token}`, ...(body !== undefined ? { "content-type": "application/json" } : {}) },
      ...(body !== undefined ? { body: JSON.stringify(body) } : {}),
    });
    const json: unknown = await res.json().catch(() => null);
    if (!res.ok) {
      const err = ApiErrorSchema.safeParse(json);
      if (err.success) throw new ApiRequestError(res.status, err.data.error.code, err.data.error.message, err.data.error.retryAfterMs);
      throw new ApiRequestError(res.status, "INTERNAL", `요청 실패 (${res.status})`);
    }
    const parsed = schema.safeParse(json);
    if (!parsed.success) throw new ApiRequestError(res.status, "INTERNAL", "서버 응답 형식이 올바르지 않습니다.");
    return parsed.data;
  }
}
```

```ts
import type { ChatDoneEvent, ChatErrorEvent, ChatStatusEvent, ChatTraceEvent, ErrorCode, Turn } from "@jev-chat/protocol";

/** [U2] uncertain=true: ack를 받지 못해 서버 수락 여부를 모름 → 같은 clientMsgId로 복구 재전송 */
export interface SendError {
  code: ErrorCode;
  message: string;
  retryable: boolean;
  uncertain: boolean;
}

export type UiTurn = Turn & {
  localId: string;
  stage?: "queued" | "judging" | "answering";
  sendError?: SendError;
};

export interface TurnsState {
  sessionId: string | null;
  byClientId: Record<string, UiTurn>;
  traces: Record<string, Record<string, unknown>>;
}

export type TurnsAction =
  | { type: "hydrate"; sessionId: string; turns: Turn[] }
  | { type: "localSend"; sessionId: string; clientMsgId: string; text: string }
  | { type: "ack"; sessionId: string; clientMsgId: string; turnId: string; turnSeq: number }
  | { type: "ackFailed"; sessionId: string; clientMsgId: string; error: SendError }
  | { type: "status"; e: ChatStatusEvent }
  | { type: "done"; e: ChatDoneEvent }
  | { type: "error"; e: ChatErrorEvent }
  | { type: "trace"; sessionId: string; e: ChatTraceEvent }
  | { type: "reset" };

export const initialTurns: TurnsState = { sessionId: null, byClientId: {}, traces: {} };

const isTerminal = (t: { status: string }) => t.status === "completed" || t.status === "failed";
let localCounter = 0;

function blank(clientMsgId: string): UiTurn {
  return { localId: `l${++localCounter}`, turnId: "", turnSeq: 0, clientMsgId, userText: "", status: "processing" };
}

function put(state: TurnsState, clientMsgId: string, patch: (t: UiTurn) => UiTurn): TurnsState {
  const prev = state.byClientId[clientMsgId] ?? blank(clientMsgId);
  return { ...state, byClientId: { ...state.byClientId, [clientMsgId]: patch(prev) } };
}

/** 로컬 전용 표시(진행 단계·전송 오류) 제거 — 서버 terminal 결과가 우선한다 [U2] */
function stripLocal(t: UiTurn): UiTurn {
  const { stage: _stage, sendError: _sendError, ...rest } = t;
  return rest as UiTurn;
}

/** [U8] 비어 있는 메타데이터만 보충 */
function fillMeta(prev: UiTurn, t: { turnId?: string; turnSeq?: number; userText?: string }): UiTurn {
  return { ...prev, turnId: prev.turnId || t.turnId || "", turnSeq: prev.turnSeq || t.turnSeq || 0, userText: prev.userText || t.userText || "" };
}

export function turnsReducer(state: TurnsState, a: TurnsAction): TurnsState {
  switch (a.type) {
    case "reset":
      return initialTurns;
    case "hydrate": {
      let s: TurnsState = state.sessionId === a.sessionId ? state : { ...initialTurns, sessionId: a.sessionId };
      for (const t of a.turns) {
        s = put(s, t.clientMsgId, (prev) => {
          if (isTerminal(prev) && !isTerminal(t)) return fillMeta(prev, t); // [U8]
          const merged: UiTurn = { ...prev, ...t, localId: prev.localId };
          return isTerminal(t) ? stripLocal(merged) : merged;
        });
      }
      return s;
    }
    case "localSend":
      if (a.sessionId !== state.sessionId) return state; // [U3]
      return put(state, a.clientMsgId, (prev) =>
        isTerminal(prev) ? prev : { ...stripLocal(prev), userText: a.text, status: "processing", stage: "queued" },
      );
    case "ack":
      if (a.sessionId !== state.sessionId) return state;
      return put(state, a.clientMsgId, (prev) => ({ ...prev, turnId: prev.turnId || a.turnId, turnSeq: prev.turnSeq || a.turnSeq }));
    case "ackFailed":
      if (a.sessionId !== state.sessionId) return state;
      // [U2] 이미 terminal이면(예: done이 먼저 옴) ack 실패는 의미가 없다
      return put(state, a.clientMsgId, (prev) => (isTerminal(prev) ? prev : { ...prev, sendError: a.error, stage: undefined }));
    case "status":
      if (a.e.sessionId !== state.sessionId) return state;
      // status는 서버가 수락했다는 증거 → 미확정 오류 해제 [U2]
      return put(state, a.e.clientMsgId, (prev) =>
        isTerminal(prev) ? prev : { ...prev, turnSeq: a.e.turnSeq, stage: a.e.stage, sendError: undefined },
      );
    case "done":
      if (a.e.sessionId !== state.sessionId) return state;
      return put(state, a.e.clientMsgId, (prev) => {
        if (isTerminal(prev)) return fillMeta(prev, { turnId: a.e.turnId, turnSeq: a.e.turnSeq }); // [U8]
        return stripLocal({
          ...prev,
          turnId: a.e.turnId,
          turnSeq: a.e.turnSeq,
          status: "completed",
          assistantText: a.e.text,
          route: a.e.route,
          sources: a.e.sources,
          traceId: a.e.traceId,
          ...(a.e.error ? { error: a.e.error } : {}),
        });
      });
    case "error":
      if (a.e.sessionId !== state.sessionId) return state;
      return put(state, a.e.clientMsgId, (prev) => {
        if (isTerminal(prev)) return fillMeta(prev, { turnSeq: a.e.turnSeq }); // [U8]
        return stripLocal({ ...prev, turnSeq: a.e.turnSeq, status: "failed", error: { code: a.e.code, retryable: a.e.retryable } });
      });
    case "trace":
      if (a.sessionId !== state.sessionId) return state;
      return { ...state, traces: { ...state.traces, [a.e.traceId]: a.e.trace } };
  }
}

export function orderedTurns(state: TurnsState): UiTurn[] {
  const all = Object.values(state.byClientId);
  const seq = all.filter((t) => t.turnSeq > 0).sort((a, b) => a.turnSeq - b.turnSeq);
  const pending = all.filter((t) => t.turnSeq === 0).sort((a, b) => Number(a.localId.slice(1)) - Number(b.localId.slice(1)));
  return [...seq, ...pending];
}
```

```ts
  private socket: SocketLike | null = null;
  private handlers: [string, Handler][] = [];
  private currentSession: string | null;
  private ready = false;
  /** [U3] close마다 증가 — 이전 연결의 이벤트·응답 무시 */
  private connGen = 0;
  /** [U3] 동기화(새 세션 포함)마다 증가 — 이전 session:start 응답 무시 */
  private syncGen = 0;
  private readonly newId: () => string;

  constructor(private readonly opts: ChatClientOptions) {
    this.newId = opts.newId ?? (() => crypto.randomUUID());
    this.currentSession = opts.resumeSessionId ?? null;
  }

  get sessionId(): string | null {
    return this.ready ? this.currentSession : null;
  }

  connect(): void {
    const gen = ++this.connGen;
    const factory: IoFactory = this.opts.ioFactory ?? ((url, o) => io(url, o) as unknown as SocketLike);
    const s = factory(`${this.opts.url}/chat`, {
      auth: { token: this.opts.token, protocolVersion: PROTOCOL_VERSION },
      transports: ["websocket"],
      reconnection: true,
      autoConnect: false,
    });
    this.socket = s;
    const on = (event: string, h: (...a: any[]) => void) => {
      const guarded = ((...a: any[]) => {
        if (gen === this.connGen) h(...a);
      }) as Handler;
      s.on(event, guarded);
      this.handlers.push([event, guarded]);
    };
    on("connect", () => {
      this.opts.onConn({ kind: "connected" });
      void this.startSession(this.currentSession ?? undefined, undefined, "sync");
    });
    on("disconnect", (reason: string) => {
      this.ready = false;
      this.opts.onConn({ kind: "disconnected", reason });
      this.opts.onSession({ kind: "syncing" });
    });

      const message = err instanceof Error ? err.message : "";
      const code = ErrorCodeSchema.safeParse(message);
      this.opts.onConn(code.success ? { kind: "rejected", code: code.data } : { kind: "disconnected", reason: message || "connect_error" });
    });

    on("chat:trace", (raw: unknown) =>
      this.relay("chat:trace", ChatTraceEventSchema, raw, (e) => ({ type: "trace", sessionId: this.currentSession ?? "", e })),
    );
    this.opts.onConn({ kind: "connecting" });
    s.connect();

  private relay<T>(where: string, schema: z.ZodType<T>, raw: unknown, toAction: (e: T) => TurnsAction): void {
    const parsed = schema.safeParse(raw);
    if (!parsed.success) {
      this.opts.onProtocolError?.(where);
      return;
    }
    this.opts.dispatch(toAction(parsed.data));
  }

  /** sync: 연결·재연결·새 세션 동기화(세션 상태를 바꿈), older: 이전 대화 페이지 */
  private async startSession(sessionId: string | undefined, beforeTurnSeq: number | undefined, mode: "sync" | "older"): Promise<boolean> {
    const s = this.socket;
    if (!s) return false;
    const conn = this.connGen;
    const sync = mode === "sync" ? ++this.syncGen : this.syncGen;
    if (mode === "sync") {
      this.ready = false;
      this.opts.onSession({ kind: "syncing" });

    const raw = await s
      .timeout(ACK_TIMEOUT)
      .emitWithAck("session:start", payload)
      .catch(() => UNCERTAIN);
    if (conn !== this.connGen || sync !== this.syncGen) return false; // [U3] 오래된 응답

      return false;

    if (!parsed.success) {
      this.opts.onProtocolError?.("session:start"); // [U1]
      return fail("INTERNAL");
    }
    if (!parsed.data.ok) return fail(parsed.data.error.code);
    const d = parsed.data.data;
    this.currentSession = d.sessionId;
    this.opts.dispatch({ type: "hydrate", sessionId: d.sessionId, turns: d.turns });
    this.opts.onHistory?.({ hasMore: d.hasMore, nextBeforeTurnSeq: d.nextBeforeTurnSeq ?? null }, mode); // [U9]

      this.opts.onSession({ kind: "ready", sessionId: d.sessionId });

    } else {
      const e = ack.data.error;
      this.opts.dispatch({ type: "ackFailed", sessionId: sid, clientMsgId, error: { code: e.code, message: e.message, retryable: e.retryable, uncertain: false } });
    }
  }

  /** [U2] 미확정 실패는 같은 clientMsgId로 복구 재전송(서버 멱등), 확정 실패만 새 ID + retryOfTurnSeq */
  retry(turn: UiTurn): Promise<void> {
    if (turn.sendError?.uncertain) return this.send(turn.userText, { clientMsgId: turn.clientMsgId });
    return this.send(turn.userText, turn.turnSeq > 0 ? { retryOfTurnSeq: turn.turnSeq } : {});
  }

  close(): void {
    this.connGen++;
    this.syncGen++;
    this.ready = false;
    for (const [event, h] of this.handlers) this.socket?.off(event, h);
    this.handlers = [];
    this.socket?.disconnect();
    this.socket = null;
  }
}
```

```ts
import { ChatClient, type ConnState, type HistoryMeta, type IoFactory, type SessionState } from "@/lib/chat-client";
import { API_URL } from "@/lib/token-store";
import { initialTurns, orderedTurns, turnsReducer, type UiTurn } from "@/lib/turns";

/**
 * 채팅 세션 수명은 App 수준이다(화면 전환에도 유지) [U9].
 * authEpoch가 바뀌면(로그인·로그아웃·토큰 교체) 상태를 비우고 새 세션으로 시작한다 [U6].
 * reconnect()는 같은 인증 세대 안에서 마지막 세션으로 재개한다 [U4].
 */
export function useChat(token: string | null, authEpoch: number, opts: { ioFactory?: IoFactory } = {}) {
  const [state, dispatch] = useReducer(turnsReducer, initialTurns);
  const [conn, setConn] = useState<ConnState>({ kind: "idle" });
  const [session, setSession] = useState<SessionState>({ kind: "none" });
  const [history, setHistory] = useState<HistoryMeta>({ hasMore: false, nextBeforeTurnSeq: null });
  const [protocolErrors, setProtocolErrors] = useState(0);
  const [nonce, setNonce] = useState(0);
  const clientRef = useRef<ChatClient | null>(null);
  const lastSession = useRef<{ epoch: number; sessionId: string } | null>(null);
  const { ioFactory } = opts;

  useEffect(() => {
    const resume = lastSession.current?.epoch === authEpoch ? lastSession.current.sessionId : undefined;
    if (!resume) {
      dispatch({ type: "reset" });
      setHistory({ hasMore: false, nextBeforeTurnSeq: null });
    }
    setSession({ kind: "none" });
    if (!token) {
      setConn({ kind: "idle" });
      return;
    }
    const c = new ChatClient({
      url: API_URL,
      token,
      dispatch,
      onConn: setConn,
      onSession: (s) => {
        setSession(s);
        if (s.kind === "ready") lastSession.current = { epoch: authEpoch, sessionId: s.sessionId };
      },
      onHistory: (m) => setHistory(m),
      onProtocolError: () => setProtocolErrors((n) => n + 1),
      ...(resume ? { resumeSessionId: resume } : {}),
      ...(ioFactory ? { ioFactory } : {}),
    });
    clientRef.current = c;
    c.connect();
    return () => {
      c.close();
      if (clientRef.current === c) clientRef.current = null;
    };
  }, [token, authEpoch, nonce, ioFactory]);

  const send = useCallback((text: string) => clientRef.current?.send(text) ?? Promise.reject(new Error("연결되지 않았습니다.")), []);
  const retry = useCallback((t: UiTurn) => clientRef.current?.retry(t) ?? Promise.reject(new Error("연결되지 않았습니다.")), []);
  const newSession = useCallback(async () => {
    lastSession.current = null;
    await clientRef.current?.newSession();
  }, []);
  const loadOlder = useCallback(async () => {
    if (history.nextBeforeTurnSeq !== null) await clientRef.current?.loadOlder(history.nextBeforeTurnSeq);
  }, [history.nextBeforeTurnSeq]);
  const reconnect = useCallback(() => setNonce((n) => n + 1), []);

  const turns = useMemo(() => orderedTurns(state), [state]);
  return { state, turns, conn, session, history, protocolErrors, send, retry, newSession, loadOlder, reconnect };
}

export type ChatHandle = ReturnType<typeof useChat>;
```

```ts
import { z } from "zod";

const Num = z.number().finite();
const Candidate = z.object({
  kind: z.enum(["faq", "chunk"]),
  id: z.string(),
  bm25Rank: Num,
  relevance: Num.optional(),
  faqProb: Num.optional(),
  status: z.string().optional(),
});
const TraceSchema = z.object({
  route: z.string(),
  bStatus: z.string(),
  intent: z.string().nullable().optional(),
  intentProbs: z.record(z.string(), Num).nullable().optional(),
  inScope: Num.nullable().optional(),
  ambiguity: Num.nullable().optional(),
  faqChoice: z.string().nullable().optional(),
  faqProb: Num.nullable().optional(),
  totalInputTokens: Num.optional(),
  latencyMs: z.object({ retrieval: Num, turn: Num.nullable(), relevance: Num.nullable(), total: Num }).optional(),
  candidates: z.array(Candidate).default([]),
});

export interface TraceView {
  route: string;
  bStatus: string;
  intent: string | null;
  intents: { id: string; prob: number }[];
  inScope: number | null;
  ambiguity: number | null;
  faqChoice: string | null;
  faqCandidates: { id: string; rank: number; prob: number | null }[];
  chunkCandidates: { id: string; rank: number; relevance: number | null; status: string }[];
  latency: { retrieval: number; turn: number | null; relevance: number | null; total: number } | null;
  totalInputTokens: number | null;
}

export function toTraceView(raw: unknown): TraceView | null {
  const p = TraceSchema.safeParse(raw);
  if (!p.success) return null;
  const t = p.data;
  return {
    route: t.route,
    bStatus: t.bStatus,
    intent: t.intent ?? null,
    intents: Object.entries(t.intentProbs ?? {}).map(([id, prob]) => ({ id, prob })).sort((a, b) => b.prob - a.prob),
    inScope: t.inScope ?? null,
    ambiguity: t.ambiguity ?? null,
    faqChoice: t.faqChoice ?? null,
    faqCandidates: t.candidates.filter((c) => c.kind === "faq").map((c) => ({ id: c.id, rank: c.bm25Rank, prob: c.faqProb ?? null })),
    chunkCandidates: t.candidates.filter((c) => c.kind === "chunk").map((c) => ({ id: c.id, rank: c.bm25Rank, relevance: c.relevance ?? null, status: c.status ?? "-" })),
    latency: t.latencyMs ?? null,
    totalInputTokens: t.totalInputTokens ?? null,
  };
}
```

```tsx
function problemOf(t: UiTurn): { message: string; retryable: boolean } | null {
  if (t.sendError) return { message: t.sendError.message, retryable: t.sendError.retryable };
  if (t.error && (t.status === "failed" || t.route === "error")) return { message: t.error.code, retryable: t.error.retryable };
```

```tsx
    queryFn: () => api.get("/api/admin/config", AdminConfigSchema),
    enabled: !!token,
  });
  return (
    <div className="max-w-2xl space-y-4 p-4 text-sm">
      <label className="block space-y-1">
        <span>접속 토큰</span>
        <Input type="password" aria-label="접속 토큰" value={draft} onChange={(e) => setDraft(e.target.value)} autoComplete="off" />
      </label>
      <div className="flex gap-2">
        <Button onClick={() => { onSave(draft); setDraft(""); }} disabled={!draft.trim()}>저장</Button>
        {token && <Button variant="outline" onClick={onLogout}>로그아웃</Button>}
      </div>
      {token && config.isFetching && !config.data && <p className="text-muted-foreground">설정을 불러오는 중…</p>}
      {token && config.error && <p className="text-destructive">{errorText(config.error)}</p>}
      {token && config.data && <pre className="whitespace-pre-wrap rounded border p-3">{JSON.stringify(config.data, null, 2)}</pre>}
    </div>
  );
}
```

`LogsPage`·`ReviewPage`·`KnowledgePage`는 `SettingsPage`와 같은 방식으로 작성한다: props `{ enabled: boolean; authEpoch: number }`, `useQuery({ queryKey: ["sessions", authEpoch, route, cursor], queryFn, enabled })` 형태, 목록은 shadcn `Table` 마크업, 페이지네이션은 `nextCursor`를 상태로 들고 "더 보기"로 이어 붙인다, `enabled`가 false면 "토큰을 먼저 입력하세요" 안내. `TraceSheet`는 `Sheet` 안에 `useQuery({ queryKey: ["trace", authEpoch, traceId], queryFn: () => api.get(\`/api/traces/${traceId}\`, TraceDetailSchema), enabled: !!traceId })` 결과의 `data.data`를 `JudgmentPanel`에, `reviews`를 목록으로 보여준다. 검수 저장은 `useMutation({ mutationFn: (r: ReviewRequest) => api.post(\`/api/traces/${id}/review\`, r, ReviewSchema), onSuccess: () => queryClient.invalidateQueries({ queryKey: ["reviews", authEpoch] }) })`. 재로드는 `useMutation({ mutationFn: () => api.post("/api/admin/knowledge/reload", undefined, ReloadResponseSchema), onSuccess: (r) => toast(r.changed ? "새 버전을 적용했습니다." : "변경 사항이 없습니다."), onError: (e) => toast.error(errorText(e)) })`.

`jev-front/src/App.tsx` [U6][U9]:
```tsx
import { useState } from "react";
import { useQueryClient } from "@tanstack/react-query";
import { Toaster } from "@/components/ui/sonner";
import { useChat } from "@/hooks/use-chat";
import type { IoFactory } from "@/lib/chat-client";
import { clearToken, getToken, setToken } from "@/lib/token-store";
import { ChatPage } from "@/features/chat/ChatPage";
import { KnowledgePage } from "@/features/knowledge/KnowledgePage";
import { LogsPage } from "@/features/logs/LogsPage";
import { ReviewPage } from "@/features/review/ReviewPage";
import { SettingsPage } from "@/features/settings/SettingsPage";

const PAGES = ["테스트 채팅", "대화 로그", "검수 대기", "지식 데이터", "설정"] as const;
type Page = (typeof PAGES)[number];

export function App({ ioFactory }: { ioFactory?: IoFactory } = {}) {
  const queryClient = useQueryClient();
  const [token, setTokenState] = useState<string | null>(() => getToken());
  const [authEpoch, setAuthEpoch] = useState(0);
  const [page, setPage] = useState<Page>(() => (getToken() ? "테스트 채팅" : "설정"));
  // [U9] 채팅 세션은 App 수명 — 화면을 바꿔도 연결·대화가 유지된다
  const chat = useChat(token, authEpoch, ioFactory ? { ioFactory } : {});

  /** [U6] 인증이 바뀌면 진행 중 요청 취소 → 캐시 비움 → 세대 증가(채팅 연결 교체, 페이지 상태 초기화) */
  const resetAuth = () => {
    void queryClient.cancelQueries();
    queryClient.clear();
    setAuthEpoch((e) => e + 1);
  };
  const save = (t: string) => {
    setToken(t);
    setTokenState(getToken());
    resetAuth();
  };
  const logout = () => {
    clearToken();
    setTokenState(null);
    resetAuth();
    setPage("설정");
  };

  return (
    <div className="grid h-screen grid-cols-[12rem_1fr]">
      <nav className="space-y-1 border-r p-3">
        {PAGES.map((p) => (
          <button key={p} type="button" onClick={() => setPage(p)} className={`block w-full rounded px-2 py-1 text-left text-sm ${page === p ? "bg-muted font-medium" : "hover:bg-muted"}`}>
            {p}
          </button>
        ))}
      </nav>
      <main className="flex h-screen flex-col overflow-hidden">
        <h1 className="border-b px-4 py-2 text-base font-semibold">{page}</h1>
        <div className="flex-1 overflow-auto" key={authEpoch}>
          {page === "테스트 채팅" && <ChatPage chat={chat} hasToken={!!token} />}
          {page === "대화 로그" && <LogsPage enabled={!!token} authEpoch={authEpoch} />}
          {page === "검수 대기" && <ReviewPage enabled={!!token} authEpoch={authEpoch} />}
          {page === "지식 데이터" && <KnowledgePage enabled={!!token} authEpoch={authEpoch} />}
          {page === "설정" && <SettingsPage token={token} authEpoch={authEpoch} onSave={save} onLogout={logout} />}
        </div>
      </main>
      <Toaster />
    </div>
  );
}
```
※ 사이드바는 shadcn `sidebar` 컴포넌트로 바꿔도 되지만, 테스트가 요구하는 접근성 이름(버튼 이름 = 화면 이름, `h1` = 화면 이름)을 유지한다.
