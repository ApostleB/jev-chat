## 개정으로 생긴 Major 이상 문제

지적 없음. P5의 작은 저장 기한 문제는 기본값에서 발생하지 않는 Minor 경계 문제로 판정했다. 선언된 FK·트랜잭션·동시 import 안전성은 구현 후 실제 DB에서 검증해야 한다.

## 구현 의견: Go

**가상 데이터 MVP 구현 Go.** Task 0 선행 수정 후 나머지 작업을 진행해도 된다. P5의 기한 범위 보완과 P9의 느린 저장 회귀 테스트를 해당 구현 작업에 포함한다. DB 통합 실행·Prisma validate·생성 클라이언트 typecheck·FK migration 확인 없이 구현 완료로 판정하지 않는다.
